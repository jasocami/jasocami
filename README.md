### 🧭 How I work

- **Root cause over quick fix.** A patch that hides the bug is a bug with a delay.
- **Simple beats clever.** The best architecture is the one the next developer understands on a Monday morning.
- **Measure, then optimise.** Profilers before opinions (yes, I built [one](https://github.com/jasocami/cprofile-and-dashboard)).
- **Ship it, then make it better.** Production is where products start, not where they end.
